# Corpus Data — Dholuo

This folder contains nightly exports of all approved Dholuo entries.

| File | Format | Use |
|------|--------|-----|
| `dholuo.jsonl` | JSONL | LLM fine-tuning, NLP research |
| `dholuo.csv` | CSV | Spreadsheet, linguistic analysis |

Files are updated automatically when new entries are approved.
